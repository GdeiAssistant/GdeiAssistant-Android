# Audited Android homepage (UI plan pages 3 and 6)

`GeneratedDesignTokens.kt` is copied without edits from GdeiAssistant/GdeiAssistant
`design/generated/GeneratedDesignTokens.kt`, generated by shared-token PR #288.
The existing Material color roles consume its palette through same-value aliases;
the 14dp card shape and 16dp page spacing also consume the generated references.
Material typography roles remain in place, while homepage course/metadata text
uses the generated title, headline, callout and caption sizes.

The homepage continues to use the existing authenticated `api/schedule`, card,
profile and announcement repositories. Today is the campus date in Asia/Shanghai.
The returned current week and each course's min/max week bounds determine which
courses belong to today. Null payloads, missing/invalid current week or missing
day/week bounds are unavailable, never a successful empty day. Failure remains
visible even when an exception has no message.

The schedule model has no start/end timestamps. The old hand-written clock table
and missing-row/length defaults were removed from the homepage: it displays only
the actual `scheduleLesson` and does not infer a next class, remaining classes or
the design's 14:30 example. Missing lesson labels are omitted. Existing real
balance data, navigation and permissions are preserved; no sample balance or
pending-item count is introduced.

The 17 routes already present in the homepage catalog use the matching Web
`Home.vue` Lucide 1.0.0 symbols, converted to native `HomeFeatureIcons` ImageVectors.
SVG path data is retained; circle/ellipse/line/rounded-rectangle primitives are
represented by equivalent path commands. Stroke is 1.8, unfilled, with round caps
and joins. The native vectors have no fixed brand tint: `Icon` receives the
current Material primary color in both themes. Each vector is cached once.
The original catalog, labels and routes remain intact, and an unmapped future
entry falls back to its original catalog icon. Other screens and navigation icons
are unchanged. Lucide/Feather permission notices are in `design/LUCIDE-LICENSE`.

Local checks compile the actual timetable models, production selector and JUnit
contract tests with the official standalone Kotlin compiler and Temurin JDK. The
external harness supplies only the Compose `Immutable` annotation needed by the
otherwise JVM-only models, and JUnit runs with socket permissions denied. This
checks timetable behavior, not Android runtime or Compose rendering. The actual
Compose 1.11.4 Android artifact classes from the repository's BOM separately
compile and instantiate all 17 production vectors on the JVM: viewport, stroke,
unfilled geometry, unspecified tint and caching contracts are checked without
rendering. That external harness supplies exact existing route constants, not a
new router. Kotlin compiler PSI parsing separately checks changed source syntax.
Locale resource checks use the repository's existing Python scripts.

Android SDK/emulator is unavailable here. Full `testDebugUnitTest`, `lintDebug`,
`assembleDebug`, Compose type checking and screenshot/device checks remain pending
in Android CI/a configured Android environment. Keep this change as a draft until
those checks pass. See the official [Kotlin command-line compiler](https://kotlinlang.org/docs/command-line.html)
and [Compose custom design-system](https://developer.android.com/develop/ui/compose/designsystems/custom)
documentation.
